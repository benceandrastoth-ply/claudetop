Privacy policy

Last updated 25 October 2026

The short version: claudetop doesn't collect anything. The app works entirely on your computer and never connects to the internet, and this website uses no cookies, analytics or tracking.

The app

To do its job, claudetop reads a few things on your computer. All of it stays there.

  • Claude Code's status. If you let the installer connect it, claudetop adds hooks to ~/.claude/settings.json. When Claude Code starts, uses a tool, finishes or stops, the hook saves a small status file in ~/.claude/claudetop/sessions/: the event, the project folder, the tool name, the time, and which programs the session runs in. Files older than a day are deleted.
  • The window in front. Its title and program name, to know whether you're looking at Claude Code, and, with Lock-in mode on, whether a browser tab's title matches its list of adult sites. Also its size and position, so Claude can get out of the way of fullscreen games and videos, and its title to notice other AI assistants.
  • The browser's tab strip, only when Lock-in mode closes a tab, to find where the tab is on screen.
  • What's playing. The app, artist, title and album that Windows' media controls report, so Claude can dance to music or watch videos with you.
  • Whether an app is using your microphone, so it can keep quiet during calls. It checks the list Windows keeps of apps using the microphone (on Linux, PulseAudio's list of recordings). It never records or hears anything.
  • Whether a Hitman game is running, by looking at the names of running programs, so Claude can suit up.
  • A few counts for the daily recap and the achievements, like finished tasks and minutes of work, saved in %APPDATA%\claudetop\stats.json. Only the last 60 days are kept.
  • Which window to bring up. When you click the little Claude, it brings the window that session runs in to the front. That's the only time it switches windows.
  • Your settings, saved in %APPDATA%\claudetop\config.json.

None of this is sent anywhere. The app contains no analytics, no crash reporting and no update checks, and makes no network connections at all. You can check: the source code is public on GitHub.

Lock-in mode is off until you turn it on. When it's on and it finds a matching tab, it closes that tab by pressing Ctrl+W for you.

Uninstalling claudetop removes its hooks. To remove everything, also delete ~/.claude/claudetop and %APPDATA%\claudetop.

This website

The site sets no cookies, stores nothing in your browser, and loads nothing from other companies: its fonts and files are all served from here. The demo at the top runs entirely in your browser.

The site is hosted on GitHub Pages, and downloads come from GitHub Releases. Like any web host, GitHub may record technical data such as your IP address when you visit or download. That's covered by the GitHub General Privacy Statement; claudetop never sees it.

Questions

Ask in the project's GitHub issues. If this policy changes, the date at the top changes with it.
