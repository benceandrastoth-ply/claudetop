A tiny Claude for your taskbar.

claudetop sits on your taskbar and acts out what Claude Code is doing. It works while Claude works, waves when Claude needs you, and celebrates when the job is done.

It always knows what Claude Code is doing

claudetop connects to Claude Code when you install it. Every session reports in, so the little Claude on your taskbar changes the moment Claude Code does. Hover over it to see each session.

    Agent 47

    Tick one box in the installer and Claude shows up in a suit. Quiet, punctual, never in a hurry. He handles problems his own way.

    Set up in a minute

    1. Download the installer

      One file. You need Windows 10 or 11 and Claude Code.

    2. Run it and keep "Connect to Claude Code" ticked

      Choose where to install it, a desktop shortcut, and whether it starts with Windows. You can also turn Claude into Agent 47 here.

    3. Start Claude Code

      Give it a task and watch the taskbar. Right-click the little Claude for every option.

    Questions

    Windows says "Windows protected your PC"

    The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway.

    What does it read on my computer?

    Claude Code's status (through hooks in ~/.claude/settings.json), the title of the window in front, and what your media player says is playing. Nothing leaves your computer.

    Does it work with the Claude app or claude.ai?

    It works with Claude Code, including Claude Code inside the desktop app. Regular chat doesn't report when it's working, so there's nothing to show.

    How do I remove it?

    Uninstall claudetop from Windows Settings. That also removes its hooks from Claude Code.
