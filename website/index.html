    Set up in a minute

    1. Download it

      One file, for 64-bit Windows 10 or 11 or 64-bit Linux. You'll also need Claude Code. On Linux, follow the Linux guide.

    2. Connect it to Claude Code

      On Windows, keep "Connect to Claude Code" ticked in the installer. On Linux, it asks the first time it starts. You can also turn Claude into Agent 47 there.

    3. Start Claude Code

      Give it a task and watch the taskbar. Right-click the little Claude for every option.

    Questions

    Windows says "Windows protected your PC"

    The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway.

    What does it read on my computer?

    Claude Code's status (through hooks in ~/.claude/settings.json), the title of the window in front, and what your media player says is playing. It never sends anything anywhere: the app makes no internet connections. The privacy policy has the full list.

    Does it run on Linux or macOS?

    Linux, yes: there's an AppImage and a .deb, and the Linux guide walks you through it. macOS, not yet.

    How do I check my download is genuine?

    Each release below lists the installer's SHA-256 fingerprint. In PowerShell, run Get-FileHash .\claudetop-Setup-*.exe in your Downloads folder and check that the hash matches.

    Does it work with the Claude app or claude.ai?

    It's made for Claude Code in a terminal or editor. Claude Code inside the Claude desktop app uses the same hooks, so it should work there too, but that hasn't been tested yet. Regular chat doesn't report when it's working, so there's nothing to show.

    How do I remove it?

    Uninstall claudetop from Windows Settings. The uninstaller also removes its hooks from Claude Code.
