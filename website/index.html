A tiny Claude for your taskbar.

claudetop sits on your taskbar and acts out what Claude Code is doing. It works while Claude works, waves when Claude needs you, and celebrates when the job is done.

It always knows what Claude Code is doing

claudetop connects to Claude Code when you install it. Every session reports in, so the little Claude on your taskbar changes the moment Claude Code does. Hover over it to see each session.

Click it and you're back in Claude Code. Running more than one session? Each gets a little Claude of its own colour, and clicking one takes you to that session.

While Claude Code works, Claude holds whatever fits the job: a magnifying glass while it searches, a pencil while it edits, a terminal while it runs commands.

    Agent 47

    Tick one box in the installer and Claude shows up in a suit. Or just start Hitman: he knows when he's needed, and changes back when you're done. Quiet, punctual, never in a hurry. He handles problems his own way.

    Set up in a minute

    1. Download it

      One file, for 64-bit Windows 10 or 11 or 64-bit Linux. You'll also need Claude Code. On Linux, follow the Linux guide.

    2. Connect it to Claude Code

      On Windows, keep "Connect to Claude Code" ticked in the installer. On Linux, it asks the first time it starts. You can also turn Claude into Agent 47 there.

    3. Start Claude Code

      Give it a task and watch the taskbar. Click the little Claude to jump back to Claude Code, right-click it for every option.

    Questions

    Windows says "Windows protected your PC"

    The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info, then Run anyway.

    What does it read on my computer?

    Claude Code's status (through hooks in ~/.claude/settings.json), the title of the window in front, and what your media player says is playing. It never sends anything anywhere: the app makes no internet connections. The privacy policy has the full list.

    Does it run on Linux or macOS?

    Linux, yes: there's an AppImage and a .deb, and the Linux guide walks you through it. macOS, not yet.

    How do I check my download is genuine?

    Each release below lists the installer's SHA-256 fingerprint. In PowerShell, run Get-FileHash .\claudetop-Setup-*.exe in your Downloads folder and check that the hash matches.

    How does it know I'm on a call?

    Windows (and Linux, through PulseAudio or PipeWire) keeps track of which apps are using your microphone. claudetop only checks whether any app is; it never hears anything. Turn this off in the right-click menu with "Quiet during calls".

    Will it get in the way when I play games?

    No. When a game (or anything else) goes fullscreen, Claude hides on that screen until you're done. You can turn this off in the right-click menu under Game mode.

    Does it work with the Claude app or claude.ai?

    It's made for Claude Code in a terminal or editor. Claude Code inside the Claude desktop app uses the same hooks, so it should work there too, but that hasn't been tested yet. Regular chat doesn't report when it's working, so there's nothing to show.

    How do I remove it?

    Uninstall claudetop from Windows Settings. The uninstaller also removes its hooks from Claude Code.
