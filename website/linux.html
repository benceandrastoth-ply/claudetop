claudetop on Linux

For 64-bit (x86-64) Linux.

There are two downloads. They're the same app; pick whichever suits your system.

  • AppImage runs on almost any distribution, with nothing to install. Download the AppImage
  • .deb is a regular package for Ubuntu, Debian, Linux Mint and Pop!_OS. It adds claudetop to your app menu and pulls in the extra tools for you. Download the .deb

Install the .deb

In a terminal, in the folder you downloaded it to:

sudo apt update
sudo apt install ./claudetop-VERSION-amd64.deb

Then start claudetop from your app menu, or run claudetop.

Run the AppImage

Make it executable once, then run it:

chmod +x claudetop-VERSION-x86_64.AppImage
./claudetop-VERSION-x86_64.AppImage

If it complains about FUSE, install it: sudo apt install libfuse2t64 on Ubuntu 24.04 and newer, libfuse2 on older Ubuntu and Debian.

The first launch

claudetop asks whether to connect to Claude Code. Say yes: it adds a few hooks to ~/.claude/settings.json so it can see what Claude Code is doing. There's also a box to turn Claude into Agent 47 right away. Everything else is in the right-click menu on the little Claude, or on its tray icon.

Extra tools for every feature

claudetop runs without these, but some features need them. The .deb installs them for you; with the AppImage, install them yourself.

  • xprop and xwininfo let claudetop see which window you're in, so it knows when you've looked at Claude Code and when a game goes fullscreen.
  • xdotool lets Lock-in mode close tabs, and lets a click on Claude bring up Claude Code.
  • playerctl lets Claude dance to your music and watch videos with you.
# Ubuntu, Debian, Mint
sudo apt install x11-utils xdotool playerctl
# Fedora
sudo dnf install xprop xdotool playerctl
# Arch
sudo pacman -S xorg-xprop xdotool playerctl

X11 and Wayland

claudetop works best in an X11 session. On Wayland (the default on recent Ubuntu and Fedora) it still runs, but Wayland doesn't let one app see another app's windows. claudetop can only see apps that run through XWayland, so:

  • It may not notice when you switch to your terminal. When work is done, Claude celebrates for a few seconds and then rests, instead of waiting for you to look.
  • Lock-in mode only works in browsers that run through XWayland.

Everything else, including the hats, panic mode, dancing and the TV, works the same.

Start at login

Right-click the little Claude and tick Start at login. That adds it to ~/.config/autostart.

Uninstall

First right-click the little Claude and untick Connected to Claude Code, so its hooks are removed. Then remove the app: sudo apt remove claudetop for the .deb, or just delete the AppImage. To remove its last traces, also delete ~/.claude/claudetop and ~/.config/claudetop.

Something not working?

Open an issue on GitHub and mention your distribution and whether you're on X11 or Wayland (echo $XDG_SESSION_TYPE tells you).
